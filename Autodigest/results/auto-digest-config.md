# 🏎️ Автомобильный дайджест — конфигурация

## Пользователь
Запросы через Telegram: команда `/Digest` или слово «подборка».
Ответы — туда же, в Telegram.

## Параметры подборки
- **Количество новостей:** до 20 (топ по релевантности)
- **Период по умолчанию:** последние 3 дня
- **Язык адженд:** русский (перевод с английского)
- **Формат:** краткая адженда + ссылка на оригинал

## Тематические интересы (приоритет)
- 🏁 **Автоспорт (всё, кроме чистых F1-новостей)** — вдвойне интересно
- 🆕 Выход новых моделей
- 📊 Аналитика рынка и прогнозы
- 🏆 Автоспортивные мероприятия
- 📝 Записки колумнистов об автокультуре, мероприятиях, мнения
- 🚗 Классические автомобили (янгтаймеры, олдтаймеры)
- ❌ НЕ интересуют: классические обзоры автомобилей (тест-драйвы, first drive)
- ⚠️ Новости, связанные с F1 косвенно (например, Aston Martin Valkyrie) — интересны

## Кеширование
- Собранный дайджест хранится до конца текущего календарного дня (Europe/Amsterdam)
- Повторный запрос без ключевого слова «новый/свежий/заново» → возвращаем закешированный
- С ключевым словом «новый», «свежий», «заново» → собираем с нуля
