# Digest Workflow — Oleg's Rules

## Язык
- В Telegram — **только русский**. Всегда.
- Сами новости могут быть на английском/немецком, но в чат — только готовый дайджест на русском.

## Режим работы
1. Запускать под-агентов **с запретом писать в чат** (инструкция: "Do NOT announce anything to the user or write in chat — just return the raw data to me quietly.")
2. Ждать результаты всех источников, прежде чем что-то отправлять.
3. Собирать единый топ-15 дайджест на русском.
4. Отправлять **один финальный дайджест** — не сырые данные, не промежуточные результаты.

## Формат дайджеста
- Топ-15, ранжированный по интересам Oleg:
  - 🥇 Автоспорт (кроме F1, но косвенно связанное с F1 — ок)
  - 🥇 Новинки и индустрия
  - 🥇 Автокультура и события
- Каждый пункт: краткое описание + ключевая информация + ссылка на источник
- Не интересует: классические обзоры машин
- Интересует: классические автомобили (янгтаймеры, олдтаймеры)
- Интересует: колумнистика, мнения, автокультура
